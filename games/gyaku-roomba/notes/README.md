# 逆ルンバ VS ルンバ

**猫は毛を撒く。ルンバは毛を吸い取る。** 90 秒でリビングの床を奪い合う、非対称の陣取りアクション。

飼い猫が家じゅうに毛をまき散らすので「逆ルンバ」と呼ばれていた、という日常の観察が発端。

## 遊び方

- 猫(逆ルンバ)かルンバを選んで、CPU と 1 対 1
- `WASD` で移動、マウスで狙ってクリック長押しで毛玉を発射(ルンバは前方を吸引)、`Space` で必殺技
- 終了時に床の過半数が猫毛なら猫の勝ち、きれいな床ならルンバの勝ち
- ルンバは床を塗らない。毛のある場所を元の床に戻すだけ、というのがこのゲームの核

## いまの状態

- できている: CPU 対戦、陣取りの集計、必殺技(換毛期バースト / 超強力おそうじ)、家具の障害物、タッチ操作(仮)
- 課題: 開始時は床が 100% きれいなのでルンバ側が有利。陣営ごとの勝率の検証、ルンバ側の爽快感、CPU が必殺技を使わない点
