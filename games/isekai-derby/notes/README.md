# 異世界ダービー：魔王討伐杯

**勇者で競馬をやれ。** 勇者パーティーたちが自動で魔王討伐を競うレースに、匿名のパトロンとして賭け、資金で勝ち筋を仕込む、競馬 × RPG × パーティーゲーム。

「これは勇者の物語ではない。勇者に金を出す者たちの物語である。」

## 遊び方(このモック)

- 出征表を見て、勝ちそうなパーティーに単勝でベットする。倍率は変動し、買った時点の倍率で固定
- レースが始まると勇者たちは自動で進む。プレイヤーは操作できない
- 資金で介入する: 装備・物資の支援、町への投資、街道整備、魔物討伐の依頼、報酬の上乗せ
- 介入は「何者かが〜」とだけ表示され、誰の仕込みかは分からない
- 決着後に全員のベットと介入を暴露。CPU パトロンの中に魔王側の黒幕が紛れていることもある
- あなた 1 人と CPU パトロン 3 人で、3 レース 1 セット

## いまの状態

- できている: 8 パーティー・6 つの型の自動進行、単勝ベット、介入、匿名ログ、全暴露、CPU の魔王パトロン
- 課題: 「勝たせたいパーティーにフル支援するだけ」になりやすい。魔王城の前で勇者が団子になる

## 次にやりたいこと

- 介入の再設計: 能力を盛るのではなく、町にアイテムを流してルートや相性を変える
- 近接 / 遠隔 / 魔法の攻撃タイプと魔王の相性、固有能力を持つ魔王
- お金を払って情報を買う仕組みと、出征表での予測ルート表示
- 最終目標は 3〜6 人の同期オンライン(Steam)
