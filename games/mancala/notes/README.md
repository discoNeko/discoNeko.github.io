# マンカラ

**穴の石を配って、ゴールに多く集めた方の勝ち。** ブラウザですぐ遊べる、シンプルなマンカラ(カラハ方式)。

## 遊び方

- 「CPU と対戦」か「2 人で対戦」を選ぶ。穴は片側 6 つ、石は各 4 個から始まる
- 自分の側の穴を選ぶと、石を反時計回りに 1 つずつ配る。相手のゴールは飛ばす
- 最後の石が自分のゴールに入ったら、もう 1 回
- 最後の石が自分側の空の穴に入り、向かいに石があれば、まとめて横取り
- 片側の穴がすべて空になったら終了。残りの石はその側のゴールへ
