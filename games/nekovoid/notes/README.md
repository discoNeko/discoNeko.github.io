# NEKOVOID — ゲーム仕様・設計議論・開発履歴

> **基準バージョン**：v5.9（オフラインPvE/PvP混合型の単体HTMLプロトタイプ）  
> **最終整理日**：2026-10-14  
> **関連ファイル**：`index.html`(元ファイル名 `neko_void_v5_9.html`)  
> **本書の目的**：ゲームデザインの意図と最新実装を一緒に保存し、継続開発・別AIへの引き継ぎ・バランス調整の基準にする。

## 0. 最重要の設計思想

**「地面に貼り付いた猫の影が、街のすべてを腹に吸い込み、できなかったことが次々にできるようになり、最終的に世界の星を丸呑みにする」ゲーム。**

単純な巨大化ゲーム（例：Hole.io）に留めず、LoLなどのMOBAにある「序盤は危険・通行困難だった地域に、成長と攻略によって進軍できるようになる」感覚を重視する。ただしMOBAを模倣するために捕食快感を犠牲にしない。

優先する体験は次の順序。

1. **巨大なものを丸呑みにする快感**：それまで食べられなかった車・建物・超巨大施設が吸い込まれて消える。
2. **食べた結果として世界が変わる**：建造物が実際の障害物で、飲み込むと新たなルートが開く。終盤の街は序盤より明らかに開けている。
3. **繰り返すたび異なる判断**：出口の選択、獲物の優先順位、進化ビルド、ライバルの妨害・横取り、星の争奪。
4. **オフラインでも敵と競い合える**：異なる性格のCPU猫3匹とPvE妨害（掃除機）によって4匹が競争する。

**失敗すべきでないこと**：プレイヤーが「近くにある物を順番に食べるだけ」「全部食べ終えても勝てずに待機するだけ」「星の前でCPUが硬直するだけ」になること。

## 1. 現在のゲーム概要（v5.9）

| 項目 | 現行仕様 |
|---|---|
| タイトル | **NEKOVOID**（猫の腹は宇宙） |
| ジャンル | 見下ろし型・捕食アクション／成長レース／オフラインPvE＋疑似PvP |
| 実装 | HTML単体、JavaScript、Canvas 2D。ローカルブラウザで起動。オンライン通信なし |
| 操作キャラ | 地面を滑る、平面状の猫の影。お腹が底なしの吸引口 |
| 参加者 | プレイヤー1匹＋CPU猫3匹（計4匹） |
| マップ | 3,600×2,600の都市。四隅のスタート街区、複数の突破口、中央の都心・星 |
| 初期サイズ | 通常の猫は **0.5m**。ドン・ニャルゴのみ **2m** |
| 勝利 | **666mに自力到達**、または**解放された中央の星を丸呑みして即666m** |
| 星解放 | 試合開始 **120秒** |
| 制限時間 | **300秒（5分）**。到達者がいなければ最終サイズ最大の猫が勝利 |
| 終盤資源 | **93秒**以降、**24秒ごと**に大型ごちそうを追加出現（配置可能なら最大4個／回） |
| 猫の解放 | 初回は「まる」のみ。試合完走ごとに1匹ずつアンロック |
| リザルト | 各猫のサイズ推移グラフ、順位、捕食数、大物捕食数、妨害・奪取数 |

### 1.1 1試合の理想的な流れ

1. **0〜30秒：小物を捕食**。カリカリ、ちゅ〜る、猫缶などで育つ。四隅の街区から開始。
2. **序盤：出口の選択**。3種の遮断物のいずれかを吸収し、外の街へ進出。選んだ出口によってボーナスが異なる。
3. **中盤：街の破壊と競争**。車・家・店舗を食べて新しい道や獲物を解禁。進化ビルドとキャラ特性に応じて、捕食効率・ルート突破・対猫戦に重点を置く。
4. **55秒：掃除機が活動開始**。プレイヤーもCPU猫も妨害対象だが、短距離追跡で振り切れる。
5. **93秒以降：超大型のごちそうが継続出現**。食料切れを防ぎ、自力666mの勝ち筋を保持。
6. **120秒：星解放**。都心の封鎖を破った猫が中央の星を奪い合う。食料狩りと星狙いの二択が生まれる。
7. **決着**。星捕食・自力666m・300秒到達のいずれかでリザルトへ。

※上の時間帯は体験設計上の目安。ゲーム内では各プレイヤーの成長やルート選択によって展開が前後する。

## 2. 基本操作と捕食

| 入力 | 動作 |
|---|---|
| `W/A/S/D`（方向キーも可） | 移動 |
| `E` 長押し、または左クリック長押し | 吸引。射程内の獲物を捕食する |
| 小物への接近 | 小物を**自動捕食**（E操作なしでも進行） |
| `Space` | ダッシュ／体当たり／敵猫の捕食妨害 |
| `Q` | 優先目標の切り替え。目標に向けた方向表示もある |
| `1` `2` `3` | 進化候補の選択（進化UI表示中） |
| `P` | ポーズ／再開 |

### 2.1 捕食の操作感

- **小物**：近づくだけで自動吸引。短時間でポコポコ食べられる。
- **中物**：一定時間、腹の吸引範囲内に保持して食べる。
- **大物・建物**：数秒かけて引きずり込み、最終的に消滅する。捕食中は移動できるが大幅に減速する（初期検討のA「完全停止」、C「自由移動」でなく、**B「低速移動」**を採用）。
- **捕食可能な獲物**：猫の成長段階に応じて増える。もちには1段階上の獲物への先取り能力がある。
- **連鎖捕食**：大物を飲み込むと周辺の小物も一緒に飲み込まれる。まる／重力胃袋ビルドが得意。

### 2.2 必須のフィードバック

- 自分の猫を中心とする**外側の輪＝E／クリックの吸引範囲**、**内側の点線＝自動捕食範囲**。
- 大物だけでなく、**自動吸引される小物にも捕食の円形進捗インジケーター**を表示。
- 対象の円は吸引によって対象が沈んでも元の場所に残る。自分・敵・競合中で色を変える（概ね水色／ピンク／黄色）。
- 丸呑みの揺れ、衝撃波、吸い込み軌跡、連鎖の粒子、成長の演出。
- 重要な捕食対象と開通地点はミニマップ・目標案内などで理解できるようにする。
- ゲーム開始時もプレイ中も**プレイヤー猫を画面中央に置く**。マップ外の余白表示は許容し、端で視点がずれて迷わないことを優先。
- リザルト・停止・キャラ選択時は**画面揺れを止める**。

## 3. マップと戦略的な地形変化

### 3.1 四隅の街区

- 4匹は**四隅の異なる位置**から出現し、開始する角は毎試合ランダムに割り当てる。
- 各街区の序盤資源は対称的に用意して、スタート位置そのものによる不利を避ける。
- 建物には物理的な通行判定があり、**食べるまで抜けられない**。大きな猫に合わせて表示と移動判定を調整する。
- 中央も検問ビル・高層街区で囲われ、成長して門を食べることで侵入可能になる。
- ただ広いだけのフィールドではない。**消した建物が新しい移動経路・戦闘空間を生む**のが重要。

### 3.2 スタート街区の3出口

| 出口 | 役割 | 現行ボーナス | 捕食時間の傾向 |
|---|---|---|---|
| **速攻の路地** | 先に外へ出て先行 | 移動速度 **+8.5%** | 短い |
| **暴食の市場** | 成長重視 | 内部食量 **+22** | 長い |
| **強襲の車庫** | 戦闘・妨害強化 | 吹き飛ばし **+50px** | 中程度 |

- 出口はどれも原則として序盤の同じ成長段階から狙える。
- 早く突破するか、稼いでから出るか、戦闘向きに育てるかを選ぶ。
- 出口を開けた後は他の猫や大型の獲物と遭遇しやすくなる。

### 3.3 マップ内の争奪施設

一度しか食べられない固有の戦略拠点：

- **吸引研究所**：吸引距離 +40px。
- **衝撃車庫**：吹き飛ばし +45px。
- **満腹デパート**：内部食量 +65（実際の獲得値は栄養効率の影響を受ける）。
- **影走り駅**：移動速度 +12%。

中央近くには巨大ちゅ〜る工場、月見タワー、世界猫缶倉庫、超巨大観覧車などの超巨大オブジェクトも配置。**中央の星は通常オブジェクトより数段大きく**、終盤の巨猫と釣り合う見た目にしている。

### 3.4 まだ残るマップ上の課題

- 固定の「必須ルート」が最適解にならないよう、出口後の資源配置・争奪点を調整する。
- ルートが開ける快感と、移動時間が長くなる退屈さの両立。
- 大型建造物を破壊しても局所的に通行不能な配置・AIの経路詰まりが起きないか。
- 建物が多い序盤と、食べ尽くされた終盤の**景色・移動の自由度の差**を十分に感じられるか。

## 4. 成長・サイズ・スコア

### 4.1 見た目のm表示と内部値は別

UIは「0.5m → 666m」と成長するが、実装では獲物の価値を累積する**内部食量（`mass`）**から表示サイズ（`meters(mass)`）を換算している。以下の対応はv5.9の実装値。

| 表示サイズ | 累積内部食量の到達値 |
|---|---:|
| 0.5m | 0 |
| 1m | 32 |
| 2m | 105 |
| 5m | 240 |
| 10m | 500 |
| 25m | 920 |
| 66m | 1,540 |
| 200m | 2,900 |
| **666m** | **5,700** |

各区間は内部食量から線形補間して表示する。したがって、数字が大きく見えることと、各捕食で内部食量が同量増えることは同義ではない。**200m→666mの成長が特に重い**設計。

### 4.2 v5.8〜v5.9の調整理由

- 当初「もち」が早く巨大な獲物を食べ、大量の食量を得て成長がさらに加速し、星が解放される前に666mへ到達した。
- v5.8で必要食量を増やし、巨大化後の栄養効率を落としたところ、**街を全部食べても約350mで止まり、星まで待つしかない**別の問題が生じた。
- v5.9では必要食量を **6,500 → 5,700**、後半の最低栄養効率を **48% → 64%** へ微調整し、追加の大型ごちそう供給を採用。
- 現行の栄養効率は内部食量が増すと段階的に **100% → 88% → 78% → 最低64%** へ減速する。丸呑み速度を大きく犠牲にせず、**食べる快感を維持しながら成長の暴走だけを抑える**。
- 「もち」の捕食速度倍率は **1.36倍**。格上の獲物を先取りした場合、栄養が **72%** になる。

### 4.3 追加の終盤ごちそう

- **93秒**以降、**24秒ごと**に新規大型オブジェクトを最大4個追加（空きスペースが確保できない場合は減る）。
- 例：**特大ちゅ〜る輸送船／巨大カリカリサイロ／猫缶宇宙船／大盛りごはん工場**。
- 成長が遅れた猫の周囲なども出現候補とし、逆転可能性を補助する。
- 出現時に道を完全に塞がないよう、中央への進路・既存の建物・猫の位置を避ける。
- **星を取らなくても666mへ到達できる**ことが重要な設計要件。無限に必ず到達できる保証ではなく、試合のテンポと総資源量を繰り返し検証する。

### 4.4 巨大化の視覚表現

- サイズが増すほど猫シルエットとお腹の穴を顕著に拡大。カメラも緩やかにズームアウト。
- 巨大化によるマップ移動の窮屈さを抑えるため、**表示サイズと物理衝突判定を分離**。
- 後半の巨大施設・星も大きくして、猫だけが巨大で獲物が小さく見える破綻を回避。

## 5. プレイ可能キャラとアンロック

| 解放条件 | 猫 | 個性 | 弱み・トレードオフ |
|---|---|---|---|
| 初期 | **まる** | バランス型。大物を飲み込んだときの**連鎖捕食**が強い | 特化型ほど単一分野では突出しない |
| 1試合完走 | **もち** | **大口・強胃**。吸引範囲が広く、1段階上の獲物を早食い可能 | 移動速度が低い。格上獲物は栄養効率が低い |
| 2試合完走 | **とら** | **俊足・強襲**。短いダッシュクールダウン、開始時から強化体当たりと壁スタン | 捕食効率が低い |
| 3試合完走 | **ドン・ニャルゴ** | **2m開始・初期進化1回**。先行・略奪向き | 移動と捕食効率が低い。早熟型 |

- もともと「とら」「くろ」はどちらもダッシュ系で重複していたため、**とらに統合**。4匹目として「ボス猫」を追加し、名称を「ドン・ニャルゴ」に確定。
- **未解放の猫もカードを開いて性能・解放条件を確認できる**が、使用は不可。
- 試合完走ごとに**1匹ずつ**順番に解放。進行は `localStorage`（キー：`nekovoid_v56_games`）へ保存。
- ローカルストレージが使えない埋め込み環境では保存が持続しない可能性がある。

## 6. 進化システム：プレイスタイルの分岐

過去の「吸引範囲+○%」「移動速度+○%」だけの小刻みな強化では、どれを選んでも操作感が変わらず**リプレイ性が不足**した。そこでv5.7からは**最初の進化で系統を1つ選び、その後はその系統の専用強化から選ぶ**方式を採用した。

| 系統 | 遊び方が変わる中核能力 | 専用強化の例 |
|---|---|---|
| **重力胃袋** | E吸引で**複数の獲物を同時捕食** | 多重捕食、磁気嵐、食物連鎖 |
| **破城獣** | ダッシュで建造物の捕食ゲージを削り、**道を破壊して進む** | 爆砕ダッシュ、連続突貫、突撃戦車 |
| **略奪猫** | ダッシュで敵猫から食量を**強奪**し、星の進捗も奪える | 暴食強奪、星盗み、追撃本能 |

- 進化候補は**画面中央下**に横並びで表示。右上に置いていた時期は気づかれにくかった。
- **進化選択中もゲーム時間は停止しない**。移動しながら `1`〜`3` またはクリックで選択できる。
- 複数回の進化が溜まった場合は順に提示。
- ドン・ニャルゴは開始時点で1回進化を選べる。
- CPUは猫の性格に合う系統を原則自動選択する（まる→重力、もち→重力、とら→破城、ドン・ニャルゴ→略奪）。

**現在の課題**：派生能力ごとの「強い判断」が本当に異なるかを継続テストする。勝率だけでなく「目標選択」「敵猫との接触数」「建物の突破数」等も比較したい。

## 7. PvP風の競争・ダッシュ・奪い合い

### 7.1 ダッシュでの妨害

- 初期ダッシュから**吹き飛ばし195px相当**。初期段階でも明快に敵を飛ばせる。
- 強化でさらに距離が伸びる。v5.9の実装は原則 `195 + 55×強化ランク + その他ボーナス`（上限385px）。
- 強化されたダッシュで壁へ衝突させると、**最大2.8秒の長時間スタン**。吹き飛んだ側は移動や吸引ができない。
- スタン中に相手の獲物を横取りする行動が成立するようにした。
- 衝突予測ライン、壁スタン表記、残り時間、捕食中断のエフェクトを表示。
- 連続妨害を防ぐ**スタン耐性・当たり判定の無敵時間**を設定。
- 建物は「食べて道を開く対象」であると同時に、**敵を叩きつける壁として残す価値**もある。

### 7.2 通常の獲物の横取り

- 敵が吸いかけている物体に自分も吸引を重ね、捕食の所有権・進捗を争う。
- 敵の吸引中にダッシュで吹き飛ばすと捕食を中断させ、蓄積進捗が減る。自分が食べ切る好機になる。
- 複数の猫が争っていることは**対象の円形インジケーターの色**で分かるようにする。
- 一方的な略奪で負けた側が初期段階へ戻らないよう、略奪時の食量の上限、現在の成長段階の保護、**7秒間の再略奪保護**を採用。

### 7.3 星の最終決戦：通常獲物と別のルール

通常の綱引き方式では**CPU同士が永遠に星を引っ張り合って硬直する**問題が起きた。これを解消するため、星だけは以下の専用ルールにした。

- **星の解放は120秒**。捕食には十分な成長（実装上、概ね25m相当の捕食段階以上）が必要。
- 吸引している猫ごとに**独立した捕食進捗（`starCharge`）**を持つ。複数の猫が同時吸引しても進捗は進む。
- 競合時は成長速度を少し抑えるが、**全員が完全停止することはない**。
- 吸引していない間は各自の星進捗が緩やかに減衰する。
- 争奪が続くと**星が先行猫に反発**し、先行猫の星進捗を減らして吹き飛ばす。出し抜きの余地を作る。
- 略奪ビルドは、接近して競合することで敵の星進捗を奪う効果を持つ。
- 星を食べ切った猫は**即666m**となり試合終了。

## 8. PvE：お邪魔掃除機

- 4台の掃除機が四隅から出現し、**55秒**から稼働。
- 以前は「プレイヤーばかり追いかける」「しつこすぎる」「四隅に残り、星の最終決戦に参加できない」問題があった。
- 現行仕様では**プレイヤー・CPU猫のどちらも追跡対象**。
- 追跡は**近距離に入った相手を短時間（約3.7秒）だけ**。遠ざかると諦めて巡回へ戻り、休止時間が入る。
- 掃除機は序盤の街区から徐々に道路全域・中央近くへ巡回範囲を拡大。星の目の前に常駐するわけではない。
- 接触すると短い硬直と捕食中断を起こすが、極端に進捗を巻き戻さない。
- **ダッシュで掃除機に接触すれば撃退可能**。逃走と反撃を選べるようにして、ストレス要因にしすぎない。

## 9. CPUとのオフライン対戦

### 9.1 編成モード

- **4種類が必ず揃う（重複なし）**：プレイヤー選択を含め、まる・もち・とら・ドン・ニャルゴが1匹ずつ。
- **全員ランダム（重複あり）**：操作キャラは固定、残りCPU3匹は4種から独立にランダム抽選。重複する場合がある。
- 選択モードは `localStorage`（キー：`nekovoid_opponent_mode_v59`）に保存。
- 4匹の出現する角は試合ごとにシャッフル。

### 9.2 キャラごとのAI戦術

| AI | 優先する行動 | 目指す勝ち方 |
|---|---|---|
| **まる** | 平均的な獲物選択、重力系の進化と連鎖捕食 | 安定的に育ち、星か666mへ |
| **もち** | 大物・高栄養の追加補給を優先。基本は敵への攻撃を避ける | **捕食で自力666m**、または優勢な状態で星を食べる |
| **とら** | 敵猫への接近、ダッシュ妨害、壁スタン、突破口の確保 | 競合相手を止めて星を奪う |
| **ドン・ニャルゴ** | 成長している敵・捕食中の敵を積極的に狙い、奪取 | **相手が育てた成果を奪い**終盤に逆転 |

- CPUは食べられる獲物の価値・移動距離・捕食時間を評価して目標を選ぶ。
- 閉じた街区からの脱出、中央の検問ビルの突破、星への進軍を考慮する。
- 建物に詰まらないように経路探索を用いる。
- 星が解放されたら星を狙うが、もちなどは近くの大型ごちそうが有利なら捕食を継続する。
- CPUの行動が強すぎてプレイヤーが傍観する事態や、ドン・ニャルゴの略奪で敵の成長がゼロに戻る事態は避ける。

## 10. UI／リザルト／保存

### 10.1 試合中HUD

- プレイヤーの現在のサイズ（m）、次の成長段階までの進捗。
- 4匹の順位・現在サイズ。
- 制限時間と星の解放タイミング、現在のイベント。
- ダッシュの再使用時間、現在の捕食目標と範囲・進捗表示。
- ミニマップ、目標方向ガイド、イベント通知。
- 画面中央下の3択進化UI（試合は進行し続ける）。

### 10.2 リザルト

- 全猫の**時間→表示サイズ（m）**の成長推移グラフ。**縦軸は対数目盛**。
- 勝者、最終順位、終了理由（星／自力666m／時間切れ）。
- 各猫の捕食総数・大物捕食数・妨害回数・奪取回数。
- 新しい猫が解放されれば結果画面で通知。
- 「同じ猫で再挑戦」「猫を選び直す」の動線。
- 結果画面など、試合が止まっている間の**画面揺れを無効化**。

### 10.3 技術上の前提

- 配布は**単体の `.html` ファイル**。依存パッケージ不要を基本とし、PCのChromeなどでローカル起動。
- 表示はCanvas 2D。HTML/CSSのHUDを重ねる。
- オフラインCPU対戦のみ。**ネットワーク対戦・ランキングサーバー等は現状未実装**。
- 選択キャラの解放とAI編成方式にブラウザの `localStorage` を利用。
- マップ生成は試合ごとに異なる乱数を使う。実装には再現用 `?seed=` パラメータもある。
- ブラウザ内プレビューでは実行・保存に制限がある場合がある。実装検証はローカルChrome等でも行う。

### 11.1 議論の中で見送った、または現行実装に含まない案

- **本格的な3対3のレーン制MOBA**：自由に都市を食べる面白さが減るため、現状は採用せず。
- **大物を吸う間に完全停止する操作**：隙は作れるが操作不能がストレスになりやすいため、低速移動方式を採用。
- **単に食べた総価値だけで勝敗を決める**：目標が弱いため、666mへの自力到達＋星捕食の二本柱へ変更。
- **すべての能力を細かい数値バフだけにする進化**：ビルドの差が出ないため、ルールの異なる3系統に変更。
- **同時に星を吸うと互いに進捗が戻る綱引き**：膠着するため個別チャージ制へ変更。
- **吸った物を吐き出して武器にする**：初期段階で提案したが、**v5.9の中心的な実装機能ではない**。将来案として保持。
- **街灯を食べると影が増えて有利になる等の光／影の支配**：魅力的な世界観・戦術案だが、**現行の中心システムとしては未実装**。
- **プレイヤー間のオンライン通信PvP**：初期案として想定する余地はあるが、現行はオフラインCPU対戦。

## 12. 今後の検証・改善バックログ

### 最優先：ゲームが「面白い判断」を生むか

1. **自力666mと星勝利の両立**：食べ切って暇になる時間をなくしつつ、星が毎回の唯一解にならないようにする。
2. **もちの勝率と成長曲線**：格上の獲物を先取りする優位が、また暴走しないか。
3. **CPUの性格が体感として分かるか**：もち＝食料を奪う、とら＝ダッシュで邪魔する、ドン＝育った相手から奪う。リザルトの妨害・略奪数と行動を照合する。
4. **星の決着の質**：星への先着が強すぎないか。複数AIが集まっても止まらないか。残り時間によって膠着や理不尽さが生じないか。
5. **出口の価値の比較**：速攻／暴食／強襲が本当に悩める選択か。「いつも最短出口」が最適にならないか。
6. **進化ビルドの非対称性**：重力・破城・略奪の操作感や勝ち筋が違うか。固有の成功体験を作れているか。

### 技術・品質

- **多数試合の自動シミュレーション**：猫タイプ・進化系統・開始角・乱数シード別の勝率、平均決着時間、星勝利率、自力666m率、成長曲線、壁詰まり時間。
- **CPU経路探索**：巨大化・障害物破壊・補給オブジェクト追加後もスタックしないか。
- **画面の読みやすさ**：巨大猫が獲物やインジケーターを隠さないか。カメラのズームと開始時中央表示が成立するか。
- **リザルト表示**：グラフが0.5〜666mを正しく扱うか。サイズの丸めで到達条件と誤解が生じないか。
- **保存と再挑戦**：ブラウザ再読み込み後も解放状態・編成方式が残るか。結果表示を複数回開いても重複解放されないか。
- **細部の整理**：現行HTML内の`<title>`に旧版表記（05.8）が残っているため、次回改修時に正す。

### バランス調整の原則

- 捕食演出の迫力や丸呑み速度を、安易に弱体化しない。
- 暴走する場合は先に **必要食量・栄養効率・リスク・獲物総供給量・目標の奪い合い** を調整する。
- 攻撃を強くするなら、強い攻撃の予兆・位置取り・反撃手段も用意する。
- 劣勢の猫にも、立ち回りで強い獲物や星を出し抜ける余地を残す。
- 新要素は常に「巨大なものを丸呑みにする快感に貢献するか？」で評価する。

## 13. 他AI／次の開発者向け実装指針

1. **起点は `neko_void_v5_9.html`。** 各旧版の仕様を最新ファイルへ機械的に混ぜ直さない。旧版はなぜ変更したかの参考とする。
2. **最重要の快感は捕食。** 演出・スケール差・建物の消滅と開通を守る。単なる射撃ゲームにはしない。
3. **進化はルールを変える。** 数値だけの三択へ戻さず、異なるプレイスタイルを作る。
4. **星は競争する。** 同時捕食で必ず決着可能な設計を維持し、捕食中のスタン・星の反発・奪取の相互作用を検証する。
5. **CPUも試合に参加していることを見せる。** 目標選択、追跡、妨害、略奪をタイプ別に制御。公平な条件を原則とする。
6. **デバッグ可能性を保つ。** 乱数シード固定、多数試合の比較、サイズ推移のログ、役割別行動の記録を維持・拡充する。
7. **HTML単体で動くことを基本にする。** エラーなしで「キャラ選択→スタート→移動→吸引→進化→妨害→星争奪／自力成長→リザルト→再挑戦」を通せるようにする。

## 14. 要約（一文）

**NEKOVOIDは「猫の影で世界を丸呑みにする快感」を軸に、街を食べて行動可能な領域を広げ、性格の違う4匹が食料と中央の星を奪い合い、進化によって毎試合異なる勝ち方を目指す、5分間のオフライン対戦型捕食アクションである。**
