# NEKOVOID — 猫の腹は宇宙

**地面に貼り付いた猫の影が、お腹の穴で街を丸呑みにして巨大化する。** 0.5m から 666m へ。性格の違う 4 匹の猫で、食料と中央の星を奪い合う 5 分間の捕食アクション。

いちばん大事にしているのは、それまで食べられなかった巨大なものを丸呑みにする快感。

## 遊び方

- `WASD` で移動、`E` か左クリック長押しで吸引、`Space` でダッシュ・体当たり、`Q` で目標の切り替え、`1`〜`3` で進化を選ぶ
- 建物は食べるまで通れない。食べると新しい道が開け、街がだんだん開けていく
- 666m に自力で到達するか、120 秒で解放される中央の星を丸呑みすれば勝ち。300 秒経ったら最大サイズの猫の勝ち
- スタート街区の 3 つの出口(速攻 / 暴食 / 強襲)、進化の 3 系統(重力胃袋 / 破城獣 / 略奪猫)で毎回違う勝ち方になる
- 猫は 4 匹(まる / もち / とら / ドン・ニャルゴ)。試合を完走するたびに 1 匹ずつ解放。お邪魔役の掃除機もいる
