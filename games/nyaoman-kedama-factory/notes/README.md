# ニャオマンの毛玉工場

**猫のニャオマンをブラシでなでて毛を集め、洗浄・成型・圧縮して出荷する。** 限られた敷地と電力で、次にどこへ投資するかを考える工場経営 × 放置ゲーム。

飼い猫ニャオマンの大量の抜け毛が発端。主役は本人の実写写真。

## 遊び方

- 猫の写真の上でマウスを滑らせる(スマホはスワイプ)と原毛が取れる。クリック連打ではなく「なでる」操作
- 原毛 → 洗毛 → 成型 → 通常毛玉、さらに圧縮すると高級毛玉。出荷して「にゃコイン」を稼ぐ
- コインで設備を増設。敷地のマス数と電力に上限があるので、撤去や土地の購入で組み替える
- 出荷方針(量産 / 半々 / 高級)と集中稼働で、70 秒の納品契約を狙う
- 換毛フィーバーで 16 秒間採毛が 3 倍

## いまの状態(v3)

- できている: 在庫の上限と上流の停止、有限の敷地、電力の制約、出荷方針、納品契約、設備の撤去と払い戻し、セーブ
- 課題: 勝利条件やエンディングがない。設備を買ったときの効果が事前に見えにくく、雰囲気で買いがち。契約の種類が単調

## 次にやりたいこと(v4 案)

- 設備カードに「買うと利益が +X/秒」などの投資予測を出す
- 機械の稼働率や詰まりを、アニメーションと色で見せる
- 条件の違う複数の案件から受注を選べるようにする
