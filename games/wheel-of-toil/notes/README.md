# 苦役の車輪

**← → を交互に押して、巨大な石臼の棒をひたすら押し回す。** 20 年回し続けて生き延びる、three.js 製の 3D ミニゲーム(試作)。

## 遊び方

- ← → (A / D)を交互に押すと棒を押して進む。同じ側を続けて押すとつまずく。リズムよく押すと押す力にボーナス
- Space で休むとスタミナが回復する。ただし回転がノルマを下回ると「看守の目」が溜まり、満タンになると鞭が飛ぶ
- 鞭を 5 回受けると力尽きる。年が明けるたびに 1 つ回復する
- 車輪 1 周が 1 年。春夏秋冬と昼夜がめぐり、冬は雪が降る
- 年を重ねるほど体が太くなり、日焼けし、ヒゲと髪が伸びる。看守のノルマも少しずつ上がる
- 20 年目、← → の連打で棒をへし折れば自由

## いまの状態

- できている: 押して回す操作、スタミナ・ノルマ・看守の目、鞭の演出、季節と昼夜、主人公の成長、20 年目のエンディング、力尽きたときのゲームオーバー、スマホ用のボタン
- 効果音は WebAudio で合成。単体の HTML 1 枚(three.js は CDN から読み込み)
