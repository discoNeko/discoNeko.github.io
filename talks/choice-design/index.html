Game Design / Decision Architecture

面白い
意思決定は、
どう生まれるか。

「何を選べるか」ではなく、「なぜその選択に悩むのか」。

01 / DEFINITION

面白い意思決定の構造

複数の魅力的な選択肢があり、何かを得るために何かを諦める。さらに、その選択が状況に応じて価値を変え、結果を振り返れる。この条件が重なると、選択は単なる操作から「ゲームプレイ」になる。

重要なのは、選択肢の数ではない。
選ばなかった選択肢を、惜しいと思えるかだ。
01魅力の拮抗

どちらも欲しい。片方が明白な上位互換ではない。

02機会費用

選ぶことで別の利益・時間・安全を捨てる。

03文脈依存

状況や戦略が変われば、選択の価値も変わる。

04判断材料

予測に使える情報があり、完全な運試しではない。

05結果と連鎖

結果が実感でき、次の判断にも影響する。

※これは「戦略的な意思決定」を評価するための観点。すべてのゲームがこの構造を必要とするわけではない。操作の快感・探索・物語体験を中心にするゲームもある。

02 / CONTRAST

同じ三択でも、面白さは違う。

ステータスが3つ並ぶだけでは、悩む理由が生まれない。だが、現在の危機と将来の見通しを加えると、一つひとつの選択が意味を持ち始める。

× / CONTEXTLESS CHOICE

ただ数字を増やす

「攻撃力・防御力・HPのどれを上げる？」という設問。状況や構築との関係が薄ければ、好みや定石で決めるだけ。

攻撃+10防御+10HP+10

弱さの原因：それぞれの選択が解決する問題が提示されていない。

✓ / CONTEXTUAL CHOICE

失うものが見える

「HP18/50、ボスまで残り3戦。休息・武器強化・未知の遺物、どれか1つ」。何を優先するかで未来が変わる。

休息 ─ 生存率を今すぐ上げる武器強化 ─ 未来の戦闘を楽にする遺物 ─ 予測不能な突破口を狙う

強さの原因：現在の状況に対して、異なるリスクと時間軸がぶつかる。

TRY IT / CLICK TO COMPARE

あなたなら、どれを選ぶ？

残りHP18/50。ボスまで3戦。次の1回の準備行動しか選べない。

♥ 18 / 50   ◈ 3 BATTLES LEFT
CHOICE PREVIEW / 選択の結果安全を確保する

HPは48/50へ。ただし武器は強くならない。

生存の安心
次の戦闘の火力

※バーの値は考え方を伝える模式表現で、実際の勝率ではありません。

得るもの / UPSIDE

直近の全滅リスクを下げ、道中を安定させられる。

諦めるもの / TRADE-OFF

火力を強化できず、ボス戦が長引くかもしれない。

※正解判定のゲームではありません。「何を得る代わりに何を諦めるか」を可視化する設計例です。

03 / PATTERNS

意思決定を生む6つの型

面白い判断は、単一の公式から生まれない。いくつかの葛藤を組み合わせることで、短い選択でも深みが出る。

機会費用

Aを取るとBを失う。どちらも魅力的で、同時に実行できない。

例：回復か、カード強化か
リスクと報酬

安全に小さく稼ぐか、失敗を承知で大きな利益を狙うか。

例：撤退か、危険地帯への続行か
短期と長期

目先の問題を解決するか、将来の生産性に資源を投じるか。

例：設備拡張か、今の需要への対応か
情報と不確実性

偵察に時間を使うか、不完全な情報のまま挑むか。

例：敵の編成を調べるか、先制するか
目的の衝突

すべてを守れない。何を優先し、何の損失を受け入れるか。

例：味方の命か、都市の防衛か
相乗効果と方向転換

今の構築を伸ばすか、新しい勝ち筋へ乗り換えるか。

例：毒ビルドを継続するか、別戦術へ

参照イメージ：『Slay the Spire』の焚き火、『Into the Breach』の防衛判断、『Factorio』の設備投資など。ここでは固有の詳細仕様よりも、判断の構造に注目している。

04 / INFORMATION

「正解が不明」と「何も分からない」は違う。

宝箱AとBの中身が完全に不明なら、それは勘に近い。Aが確実に100G、Bが50%で300G・50%で呪いなら、リスクへの姿勢や手持ちの装備を使って考えられる。

EXERCISE / INFORMATION DESIGN

プレイヤーに、どれだけ判断材料を渡す？

スライダーを動かして、情報設計の違いを確認できます。

TWO CHESTS / 同じ二択を比べてみる情報あり：期待とリスクを比べられる
宝箱 A確実に 100G

堅実な収入。大きくは増えない。

宝箱 B50%：300G / 50%：呪い

得は大きいが、失敗の代償もある。

◉今なら「安全に稼ぐか、賭けるか」を考えられる。
ほぼ情報なし手がかりがある解答まで明示
手がかりのある不確実性

利益と危険の傾向は見えるが、最終結果は断定できない。知識や状況が判断を変える。

補足：情報量が多いこと自体は悪くない。チェスのように完全情報でも、先を読み切れなければ深い判断が成立する。重要なのは「情報が多いか」ではなく「判断に使えるか」「最適解が自明にならないか」。

05 / CONSEQUENCES

優れた選択は、次の選択を変える。

一度の選択が、その場で完結せず、未来の選択肢や価値を変える。これが「作業としての選択」と「自分の戦略を育てる体験」を分ける。

TURN 01毒強化の装備を拾う

毒を中心としたビルドを考え始める。

TURN 02毒に強いボスを知る

別の攻撃手段を仕込むか、毒を極めるか。

TURN 03毒を爆発させる遺物

安定した構成を捨てて乗り換えるか。

TURN 04結果に納得できる

過去の判断を振り返り、次の攻略を考える。

KEY INSIGHT

プレイヤーは「自分の戦略」を持つと、ゲームに主体的になる。

ただし、初手で最終ビルドが確定してしまうと後半は消化試合になる。過去の投資を活かす道と、それを捨てて転換する道の両方が存在することが重要。

06 / FAILURE MODES

「選べるのにつまらない」の正体

選択肢を増やしても、判断の面白さが増えるわけではない。むしろ選択疲れを招くこともある。

上位互換がある

同じコストなら攻撃+5より+10を選ぶ。見かけ上の選択肢しかない。

毎回の最適解が固定

特定の設備・スキルを選ぶのが常に正しいなら、覚えた瞬間から作業になる。

判断材料がゼロ

報酬も危険も分からない二択は、戦略ではなく当てずっぽうになりやすい。

結果が変わらない

何を選んでも進行が同じなら、戦略上の選択ではなく演出上の選択に近い。

小さな判断が多すぎる

毎ターン差の小さい選択を強いると、面白さよりも操作負荷が上回る。

損失だけが目立つ

すべての選択肢が罰に見えると、悩みではなくストレスになる。何を得るかも明確にする。

09 / OPEN QUESTIONS

ここから、もう一段深く考える。

このノートは完成した答えではなく、議論の出発点。次の問いは、異なるゲームジャンルや企画に応用するときに効いてくる。

何を選ぶかより「いつ選ぶか」が重要なゲームは？

同じ選択でも、タイミングによって価値が反転する設計。

後悔はどこまで快感に変えられるか？

納得できる失敗と、理不尽で萎える失敗の境界。

最適解が発見された後も面白いゲームとは？

実行技術、対人の読み合い、環境の変化、創造的な自己目標。

プレイヤーの性格が表れる選択と、戦略的な選択をどう両立する？

効率では損でも、物語としては選びたい道をどう扱うか。

選択の「数」を減らしたほうが面白くなる瞬間は？

頻度、重さ、UI負荷、選択を挟む間隔をどう設計するか。

ONE SENTENCE TO REMEMBER

「どれを選ぶか」で悩ませるより、
「何を諦めるか」で悩ませる。

そして、もっと強いゲームは「あのとき別の選択をしていたら？」を、次のプレイへの動機に変える。
