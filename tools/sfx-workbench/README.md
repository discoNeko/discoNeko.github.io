# SFX Workbench

ブラウザ上でスライダーを触りながら、ゲーム用の効果音を手続き的に合成・調整して WAV で書き出すツール。
Web Audio API(`OfflineAudioContext`)でレンダリングするので、同じ設定とシードなら毎回同じ音になる。

最初のレシピとして「ロープを引きちぎる音」を収録している。

## 起動

ビルド・サーバー不要。フォルダごと展開して `index.html` をブラウザで開くだけで動く
(外部通信・ES Modules・fetch を使っていないため file:// のままで動作する)。

開発中にローカルサーバーで開きたい場合:

```bash
python3 -m http.server 8766 --directory sfx-workbench
```

## 使い方

| 操作 | 内容 |
|---|---|
| スライダー | 動かすと即座に再描画。離すと(自動再生 ON なら)再生 |
| ラベルをダブルクリック | そのパラメータを初期値に戻す |
| `S`(ソロ) | そのレイヤーだけ聴く。Shift+クリックで複数 |
| 🔒(ロック) | 「ゆらす」「ランダム」の対象から外す(マスターは最初からロック) |
| 🎲 別テイク / `N` | パラメータはそのまま、ランダム要素(シード)だけ変える |
| ゆらす / ランダム | 現在値から少しずらす / 初期値を中心に大きく振る。振れ幅は「変化量」 |
| 比較スロット A〜D | 空きをクリックで保存、保存済みをクリックで呼び出し。Shift+クリックで上書き、右クリックで消去 |
| 波形クリック | その位置から再生 |
| `Space` / `Esc` / `⌘Z` / `⇧⌘Z` | 再生 / 停止 / 元に戻す / やり直す |
| WAV書き出し | 16/24bit PCM・32bit float、44.1/48kHz、モノラル/ステレオ |
| 一括書き出し | 現在のシードから連番で N テイク書き出す(ゲーム内でのランダム再生用) |
| JSON書き出し/読み込み | パラメータ+シードを保存・共有 |

現在の状態・スロット・ユーザープリセットは localStorage に保存される。

## ロープ破断レシピの構成

実際の破断を時間順に 5 つの現象へ分解し、それぞれ独立したレイヤーで合成している。

| レイヤー | 何の音か | 合成方法 |
|---|---|---|
| きしみ | 張力がかかった繊維の stick-slip 摩擦 | 周期が加速するクリック列 → 上昇する 2 つの共鳴バンドパス |
| 繊維の断裂 | 破断直前のプチプチ | 破断時刻に向かって集中するノイズ粒。粒ごとに共鳴周波数をばらつかせる |
| 破断 | メインの「バチッ」 | 高域クラック + バンドパスした胴鳴りノイズ + ピッチが落ちる低音サイン。分裂数で「バチバチッ」 |
| ほつれ | 破断後に裂けていく音 | 密度が減っていくポアソン粒 + ノイズ → スイープするバンドパス |
| 反動 | 切れた端の風切りと着地 | ノイズ → 下降スイープ + はためき(振幅変調)、最後に低いパタッ |

これに全レシピ共通の「空間(リバーブ)」「マスター(サチュレーション・EQ・テープピッチ・ノーマライズ)」が掛かる。

## 構成

```
index.html
css/style.css
js/core/sfx.js       名前空間・レシピ登録
js/core/rng.js       シード付き乱数(レイヤーごとに独立した系列)
js/core/dsp.js       ノイズ・JS biquad・Web Audio ヘルパー・残響IR・FFT
js/core/engine.js    レンダリング・共通グループ(空間/マスター)・WAV エンコード・試聴
js/recipes/*.js      レシピ(音の設計図)
js/ui/controls.js    パラメータ定義からスライダーを自動生成
js/ui/viz.js         タイムライン・波形・スペクトログラム
js/app.js            状態・履歴・スロット・プリセット・書き出し
```

## レシピの追加

`js/recipes/` にファイルを作り、`index.html` で `app.js` より前に読み込む。UI は定義から自動生成される。

```js
SFX.registerRecipe({
  id: 'my-sound',
  name: '表示名',
  layers: [
    {
      key: 'body', label: '本体', color: '#f7768e', gain: 0, // gain: レイヤー音量の初期値(dB)
      desc: '説明',
      params: [
        // scale: 'log' は周波数・時間向け。type: 'toggle' でチェックボックス
        { key: 'freq', label: '高さ', min: 50, max: 5000, step: 1, def: 400, unit: 'Hz', scale: 'log' },
      ],
      // ctx: OfflineAudioContext / p: このレイヤーのパラメータ / out: 接続先 GainNode
      // rng: このレイヤー専用の乱数 / plan: plan() の戻り値
      build({ ctx, p, rng, out, plan, dsp }) { /* ノードを組んで out に繋ぐ */ },
    },
  ],
  // 各レイヤーの配置時刻と全体の長さを決める。spans/markers はタイムライン表示用
  plan(params) {
    return { duration: 1, t: {}, spans: [{ key: 'body', start: 0, end: 0.5 }], markers: [] };
  },
  presets: [{ name: '標準', params: {} }],
});
```

レイヤーの `build` は音量 0 dB でピークがおおよそ -3〜0 dBFS になるよう内部で補正しておくと、レイヤー間のバランスが取りやすい。
